  bar in the trend chart, and link hover. Nowhere else.

**Layout (asymmetric, not a 3-up card grid):**
- `max-width: 1180px`, `display: grid`, `grid-template-columns: minmax(0,1fr) 300px`, `gap: 56px`.
- Wide left column: hero number, then the outlier table (the crown jewel).
- Narrow right rail: watchlist health, RPM in use, last-run status.
- One full-bleed dark band section between them for rhythm, carrying the trend chart.
- Single `@media (max-width: 900px)` collapse to one column.
- Section heights vary. Do not normalize them.

**Type craft:**
- Non-linear scale: 11 / 15 / 19 / 34 / 88 px. The 88px hero number is the point.
- Weight ramp, not one weight: 400 / 500 / 600 / 700 in use.
- Headings: negative letter-spacing (`-0.02em` on section heads, `-0.045em` on the hero number).
- `text-wrap: balance` on headings, `text-wrap: pretty` on paragraphs.
- Prose paragraphs `max-width: 66ch`.
- Labels are 11px, uppercase, `letter-spacing: .12em`, color muted. Numbers are large. That size
  contrast is the design.
- Line-heights vary by role: 1.05 hero, 1.2 headings, 1.55 body, 1.4 table.

**Texture and separation:**
- Optional grain: one inline `<svg>` `<filter>` with `feTurbulence baseFrequency="0.8"`, applied to
  a single absolutely-positioned overlay div inside the dark band only, `opacity: .07`,
  `pointer-events: none`. Never full-page.
- Non-linear spacing scale: 4 / 10 / 18 / 30 / 56 / 96 px.
- Separate with space and background, not borders. At most one hairline rule per section, and the
  table uses row background alternation rather than per-row borders.

**Hard bans:** no emoji anywhere. No external anything. Inline SVG only for icons, if any icon is
genuinely needed, single consistent stroke width. No `linear-gradient` on text.
</design_system>

`_parse_weekly_md(path)` returns `None` on any unreadable file, else:
`{"path", "file", "date", "niche", "rpm", "handles": [...], "rows": [...]}`.
- `date`: from the `# Weekly idea farm ...` line via `re.search(r"(\d{4}-\d{2}-\d{2})", line)`.
  Fall back to the same regex over the filename, then to the file mtime formatted `%Y-%m-%d`.
- `niche` and `rpm`: from the `Channels: ... | niche: ai ($6 RPM)` line, via
  `re.search(r"niche:\s*([^\s(]+)", line)` and `re.search(r"\$([\d.]+)\s*RPM", line)`. Both default
  to `None` when absent.
- `handles`: `re.findall(r"@([A-Za-z0-9_.-]+)", line)` on the same line.
- Rows: iterate lines starting with `|`, skip the header row (cell 0 lowercased is `new`) and the
  separator row (all cells are dashes). For a data line: `cells = [c.strip() for c in line.strip().strip("|").split("|")]`.
  Require `len(cells) >= 8`, else `continue`. Then map by position from both ends, which tolerates a
  pipe inside the title:
  `new = cells[0].upper() == "NEW"`, `vsub = cells[1]`, `vsmed = cells[2]`, `views = cells[3]`,
  `est = cells[4]`, `channel = cells[5]`, `link = cells[-1]`, `title = " | ".join(cells[6:-1]).strip()`.
  Normalize a `vsub` of `—`, `-`, or empty to the string `n/a`. Wrap the whole per-line block in
  `try/except Exception: continue` so one bad line can never kill the file.
- Also compute `numeric` sort helpers on each row: `_dash_num(s)` parsing `"3.89x"` to `3.89` and
  `"126.2K"` to `126200` and `"$1.3k"` to `1300`, returning `0.0` on anything unparseable. Store as
  `row["vsmed_n"]`, `row["views_n"]`, `row["est_n"]`.

`_dash_collect(report_dir=REPORT_DIR, wl=None)` returns the whole dashboard payload:
- `wl = wl if wl is not None else load_watchlist()`.
- Glob `os.path.join(report_dir, "weekly*.md")`, parse each, drop `None`, sort by `(date, file)`.
- `latest`: the newest parsed report belonging to the active list's niche when one exists, else the
  newest report overall. Match on `niche`, not filename.
- `trend`: `[{"date", "niche", "new": <count of rows with new>, "total": len(rows)} ...]` for every
  parsed report in date order, including the zero-row ones.
- `lists`: from `wl`, per list name `{"name", "niche", "count", "active": bool, "rpm": real_rpm(niche)}`.
- `rpm`: `{"value": real_rpm(active_niche), "niche": active_niche, "source": ...}` where `source` is
  one of `"your Studio number"` (the niche key or `default` key exists in rpm.json),
  `"niche tier estimate"` (fell through to `RPM_TIERS`), or `"fallback default"`. Resolve this by
  reading rpm.json directly here rather than changing `real_rpm`'s signature. Honesty about which
  number is real is a project constraint, so this field is required, not optional.
- `seen_count`: `len(json.load(...))` of `.cache/weekly_seen.json` inside a try/except, else `0`.
- `cron`: `_dash_cron_status(report_dir)`.
- Every value defaults to an empty list, empty dict, or `None`. No key may be absent.

`_dash_cron_status(report_dir=REPORT_DIR)` returns
`{"present", "log_mtime", "err_mtime", "age_days", "error_lines", "last_line"}`:
- `present` is True when `weekly-cron.log` exists.
- `age_days`: whole days between the log mtime and now, computed from `time.time()`.
- `error_lines`: count of lines in `weekly-cron.err` that start with `ERROR:`. A non-empty .err file
  is normal yt-dlp chatter and must not be reported as a failure on its own.
- `last_line`: the last non-empty line of the log, ANSI-stripped with
  `re.sub(r"\x1b\[[0-9;]*m", "", s)`, truncated to 120 chars.
- Any exception anywhere returns the dict with safe defaults, never raises.

import os, re, tempfile, scout
def gates(p, label):
    s = open(p, encoding="utf-8").read()
    # 1. no external assets of any kind
    assert "<link" not in s.lower() and "@import" not in s, label + ": external stylesheet"
    assert not re.search(r"<script[^>]*\ssrc=", s, re.I), label + ": external script"
    assert not re.search(r"url\(\s*['\"]?(https?:)?//", s, re.I), label + ": external css url()"
    assert not re.search(r"<img", s, re.I), label + ": image tag"
    for m in re.finditer(r'(src|href)\s*=\s*"([^"]*)"', s, re.I):
        a, v = m.group(1).lower(), m.group(2)
        if v.startswith(("http://", "https://", "//")):
            assert a == "href" and re.match(r"^https://(youtu\.be/|www\.youtube\.com/watch)", v), \
                label + ": external asset " + a + "=" + v
    # 2. strip verbatim third-party spans, then gate our own copy
    own = re.sub(r'<a[^>]*class="v"[^>]*>.*?</a>', "", s, flags=re.S)
    own = re.sub(r'<span[^>]*class="v"[^>]*>.*?</span>', "", own, flags=re.S)
    assert "—" not in own and "–" not in own, label + ": em/en dash in our own copy"
    assert not scout.EMOJI_RE.search(own), label + ": emoji in our own copy"
    # 3. design system actually present, defaults actually absent
    for tok in ['Iowan Old Style', 'SF Mono', '-apple-system', '#D9541E', '#F7F4EF', '#161310',
                'text-wrap: balance', 'feTurbulence', 'grid-template-columns', '<svg']:

    return s
